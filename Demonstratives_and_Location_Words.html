Português Brasileiro

As 3 Zonas

Demonstratives & Location Words
AQUI AÍ LÁ
HOW IT WORKS
Specific noun? → match gender & number (este, essa, aqueles…)
General thing / idea? → use the neutral form (isto, isso, aquilo)
Zona 1
Perto de Mim
Near ME (the speaker)
AQUI
= here
Gendered forms
masc. sg.
este
fem. sg.
esta
masc. pl.
estes
fem. pl.
estas
Neutral form
Isto
For things, ideas, or situations — no gender, never changes
INVARIABLE
💡 EST- / IST- → think Eu (me)
Examples — gendered
Este livro aqui é meu.This book is mine.
Esta casa aqui é nova.This house is new.
Estes sapatos são caros.These shoes are expensive.
Estas flores são lindas.These flowers are beautiful.
Examples — neutral
Isto é uma escada.This is a ladder.
O que é isto?What is this?
Zona 2
Perto de Você
Near YOU (the listener)
AÍ
= there (by you)
Gendered forms
masc. sg.
esse
fem. sg.
essa
masc. pl.
esses
fem. pl.
essas
Neutral form
Isso
For things, ideas, or what someone just said — never changes
INVARIABLE
💡 ESS- / ISS- → think voSSê (you)
Examples — gendered
Esse caderno aí é seu?That notebook yours?
Essa caneta não funciona.That pen doesn't work.
Esses documentos são importantes.Those docs are important.
Essas chaves são da Maria.Those keys are Maria's.
Examples — neutral
Isso não faz sentido.That doesn't make sense.
Isso mesmo!Exactly! / That's right!
Zona 3
Longe de Nós
Far from BOTH of us
LÁ
= over there
Gendered forms
masc. sg.
aquele
fem. sg.
aquela
masc. pl.
aqueles
fem. pl.
aquelas
Neutral form
Aquilo
For distant things, past events, or far-off situations — never changes
INVARIABLE
💡 AQUEL- / AQUIL- → think far Away
Examples — gendered
Aquele carro lá é caro.That car over there is expensive.
Aquela igreja é antiga.That church is old.
Aqueles prédios são novos.Those buildings are new.
Aquelas montanhas são bonitas.Those mountains are beautiful.
Examples — neutral
Aquilo foi incrível!That was incredible!
Você viu aquilo?Did you see that?
🇧🇷 In everyday Brazilian speech, esse / essa / isso covers almost everything nearby.
Este / esta / isto is more formal or written. Aquele / aquela / aquilo is always for far away.
